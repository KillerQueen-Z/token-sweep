# Documentation drift checklist

- Installation prerequisites, package names, commands, flags, and working directories.
- Environment variables, config keys, defaults, precedence, required/optional status, and secrets handling.
- API paths, methods, request/response fields, errors, pagination, authentication, and examples.
- CLI commands, exit codes, output formats, and shell snippets.
- Supported language/runtime versions and compatibility claims.
- Architecture diagrams, component ownership, data flow, deployment regions, and service names.
- Runbooks, rollback, migrations, backup/restore, alerts, and incident procedures.
- Links, file paths, renamed modules, sample files, and screenshots.
- Changelog or release claims that conflict with shipped behavior.
